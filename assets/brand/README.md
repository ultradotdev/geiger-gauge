# Ultra.dev report branding

Palette and assets match the Ultra.dev homepage as checked on September 16, 2026.

- Ultra Dusk colors: local `ultra-homepage/src/styles/ultra-dusk.css`, verified against live site CSS.
- Ultra icon: the website’s existing mark, supplied from its public assets.
- Inter 400/700 and JetBrains Mono 400: the website’s existing font files. Their SIL OFL notices are included here and embedded in generated reports.
- Assets are embedded as data URLs so reports never fetch fonts or branding remotely.
